# Module 08: Security & Multi-Tenancy

Exposing expensive GPU nodes in multi-tenant environments requires setting up security and resource isolation.

## 📚 Topics Covered
- **Namespace isolation:** Using Kubernetes NetworkPolicies and namespaces to segregate user access.
- **Hardware Isolation:** MIG partitioning to prevent cross-tenant memory leaks or interference.
- **RBAC Configuration:** Exposing GPU resource allocation metrics via restricted service accounts.
