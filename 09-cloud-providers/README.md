# Module 09: Cloud Provider Deep Dives

Each major cloud provider has a unique infrastructure design for managing GPU clusters.

## 📚 Topics Covered
- **AWS Deep Dive:** EC2 P5, P4, and G5 instance configurations, Elastic Fabric Adapter (EFA), and GPUDirect.
- **GCP Deep Dive:** A3, A2, and TPU instances, Google Kubernetes Engine (GKE) GPU node pools, and local SSD architectures.
- **Azure Deep Dive:** ND-series virtual machines, InfiniBand networking, and Azure Kubernetes Service (AKS) GPU operators.
