# Module 10: Advanced Scheduling & Orchestration

Managing complex scheduling challenges for deep learning pipelines.

## 📚 Topics Covered
- **Volcano Scheduler:** A batch scheduling system for Kubernetes designed for high-performance computing (HPC) and AI workloads (supporting queueing, fair-share, and gang-scheduling).
- **Topology-Aware Scheduling:** Restricting pods to specific socket connections and PCIe configurations.
- **Dynamic Resource Allocation (DRA):** The next-generation Kubernetes framework for claiming specialized hardware devices dynamically.
